_This blog post was human written._

deck.gl-raster enables GPU-accelerated [Cloud-Optimized GeoTIFF][cogeo] (COG) and [Zarr] visualization in [deck.gl].

This release fixes antimeridian handling, adds several new examples, and adds "explainers" to understand how deck.gl-raster works under the hood.

![](../static/img/cog-terrain-naip-pikes-peak.jpg)

[cogeo]: https://cogeo.org/
[Zarr]: https://zarr.dev/
[deck.gl]: https://deck.gl/

## Antimeridian handling

![](../static/img/fiji-antimeridian.jpg)


- crossing images: one unwrapped mesh, cut at the world edge ([#716]); on by default ([#721])
- MosaicLayer sources across 180° ([#639], @willjnz); crossing source bboxes ([#752])
- large single-level grids past ±180°, e.g. ECMWF, AEF ([#766])
- visual: before/after at 180° (old: smear across the world)
- link: antimeridian explainer ([#767])

## Mesh error measured on the map

- `maxError` in output pixels, not input pixels ([#711], [#721])
- no inverse projection needed
- polar fixes: streaks, stack overflows, stalls at 85° ([#721])
- custom-projection: 25-35% fewer triangles, ~5x faster meshing
- cost: global EPSG:4326 tiles near the poles ([#763]); [#759] if merged
- visual: reprojection explainer's input vs output toggle ([#696], [#702] @willjnz, [#712])


## MultiCOGLayer improvements

- edge tiles: image part only, no padding band ([#755], [#753])
- `resampling` prop, linear or nearest ([#775]; from @willjnz's [#640])
- signed integer and float bands, experimental ([#777]; from @earlybard's [#650])
- visual: sentinel-2 resampling selector; DEA Int16 scene

## Wider GeoTIFF support

- band-separate images, PlanarConfiguration=2 ([#635], @thatbudakguy)
- 16-bit images in Firefox ([#773])
- big-endian files, incl. LERC ([#687] @james-willis, [#705])
- per-image JPEG tables ([#769])
- alpha from color interpretation: gray+alpha, RGB plus a non-alpha 4th band ([#732])
- smaller: rotated-image bounds ([#718]), projection-origin GeoKeys ([#671]), NaN nodata ([#727])

## New examples

We have two new sections on the [examples page](/examples): "experimental" examples and "explainer" examples.

"Experimental" examples are LLM/Claude-written examples where I haven't had time to manually verify and optimize their source code. So they may not use the best code, but they work and show off various capabilities. Experimental examples may be promoted to "primary" examples in the future.

"Explainer" examples depict how internals of deck.gl-raster work, and may be useful for any curious at a deeper level.

### Custom projections (preview)

deck.gl is [currently working on](https://github.com/visgl/deck.gl/issues/10739) support for arbitrary viewing projections, and they plan to release it as part of deck.gl's next release, v10.

The custom projections example here in deck.gl-raster gives a preview of what will be capable in production code once deck.gl v10 is released.

[![](../static/img/custom-projection-antarctica-example-card.jpg)][custom projections example]

[custom projections example]: https://developmentseed.org/deck.gl-raster/examples/custom-projection/

See [#694] and [#695] for more information.

## Draping rasters over terrain

We have [a new example][cog-terrain example] for rendering a raster layer over a 3d terrain surface. This uses the deck.gl [`TerrainExtension`] to match the raster layers to the terrain surface.

[![](../static/img/cog-terrain-naip-pikes-peak.jpg)][cog-terrain example]

[`TerrainExtension`]: https://deck.gl/docs/api-reference/extensions/terrain-extension
[cog-terrain example]: https://developmentseed.org/deck.gl-raster/examples/cog-terrain/

See [#720] and [#731] for more information.

## Reliability and performance

- traversal: each tile once; pitched view 54 ms to 0.19 ms ([#689])
- common EPSG codes without a request, shared lookups ([#760])
- GPU textures freed on layer removal ([#728])
- stale-load race on source change ([#770], @charlieforward9)
- decoder worker failures: errors instead of hangs ([#771], @charlieforward9)
- isolated header-read failures ([#709])
- `isLoaded` during metadata load ([#667]); raster lighting off ([#670]); center-first loading via deck.gl 9.4 ([#669])
- parent-tile float tolerance ([#750], @orshih6); TileMatrixSet bounds + `extent` ([#684], [#688])

## Upgrade notes

- `CutlineBbox` removed, use deck.gl's `ClipExtension` instead ([#739])
- `CachedTags` and `.cachedTags` renamed ([#769])
- `PROJECTION_REGISTRY` values now promises, `registerProjection`, proj4 dependency ([#760])
- `DecoderMetadata.littleEndian` required ([#687])
- `maxError` semantics ([#721])
- Vite: `worker.format: "es"` ([#780])
