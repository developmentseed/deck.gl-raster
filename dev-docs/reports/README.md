# Reports

Research reports: a question, its answer, and the evidence. Each report cites
files, lines and URLs, and keeps its raw research notes, scripts and results in
`research_notes/<report title>/`. If you only need the conclusions, read the
file of the same name in [`../summaries/`](../summaries/).

Like [`../specs/`](../specs/), reports are historical. They describe the code
at the commits they name and aren't kept up to date.

- [OpenLayers raster comparison](OpenLayers%20raster%20comparison.md)
  (2026-11-09): reprojection meshes, rendering and usability against
  OpenLayers, with mesh benchmarks.
